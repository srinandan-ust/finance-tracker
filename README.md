# Smart Bank – Personal Finance Tools Module
 
## 📌 Project Overview
 
The **Smart Bank** capstone project integrates personal finance tools into a Django-based online banking platform. This module, `finance_tools.py`, contains **10 essential financial calculators** designed to assist users with planning and managing their finances effectively. It ensures clean, testable, and modular Python code with full integration into a secure web-based banking system.
 
---
 
## 🎯 Purpose of the Module
 
The primary objective of the `finance_tools.py` module is to:
- Provide commonly used personal finance calculators.
- Enable financial planning and decision-making.
- Ensure modularity, reusability, and robust performance.
- Serve as the backend logic for financial tools on the user dashboard of the online banking system.
 
---
 
## 🛠️ Tools Implemented in `finance_tools.py`
 
Each function is independent, input-validated, and returns results programmatically.
 
| Tool # | Tool Name                        | Function Name                      | Description |
|--------|----------------------------------|------------------------------------|-------------|
| 1      | EMI Calculator                   | `calculate_emi()`                  | Computes monthly loan installment. |
| 2      | SIP Calculator                   | `calculate_sip()`                  | Calculates SIP maturity amount. |
| 3      | FD Calculator                    | `calculate_fd()`                   | Computes maturity value for fixed deposits. |
| 4      | RD Calculator                    | `calculate_rd()`                   | Calculates recurring deposit value. |
| 5      | Retirement Savings Estimator     | `estimate_retirement_corpus()`     | Projects retirement corpus. |
| 6      | Home Loan Eligibility Estimator  | `estimate_home_loan_eligibility()` | Estimates maximum eligible home loan. |
| 7      | Credit Card Interest Calculator  | `calculate_credit_card_balance()`  | Calculates interest on outstanding credit balance. |
| 8      | Taxable Income Calculator        | `calculate_taxable_income()`       | Computes taxable income after deductions. |
| 9      | Budget Planner                   | `plan_budget()`                    | Suggests savings and investment plans. |
| 10     | Net Worth Calculator             | `calculate_net_worth()`            | Calculates current net worth. |
