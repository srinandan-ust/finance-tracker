# Smart Bank – Personal Finance Tools Module
 
## -> Project Overview
 
The **Smart Bank** project (Called the Zest Finance tracker) integrates personal finance tools into a Django-based online platform. The module, `finance_tools.py`, contains the **10 financial calculators** (listed below) designed to assist users with managing their finances effectively. It ensures clean, testable, and modular Python code with full integration into a secure web-based banking system.
 
---
 
## -> Included Financial Tools
 
Each function is independent, input-validated, and returns results programmatically.
 
| Tool # | Tool Name                             | Description |
|--------|---------------------------------------|-------------|
| 1      | EMI Calculator                        | Computes monthly loan installment. |
| 2      | SIP Calculator                        | Calculates SIP maturity amount. |
| 3      | FD Calculator                         | Computes maturity value for fixed deposits. |
| 4      | RD Calculator                         | Calculates recurring deposit value. |
| 5      | Retirement Savings Estimator          | Projects retirement corpus. |
| 6      | Home Loan Eligibility Estimator       | Estimates maximum eligible home loan. |
| 7      | Credit Card Interest Calculator       | Calculates interest on outstanding credit balance. |
| 8      | Taxable Income Calculator             | Computes taxable income after deductions. |
| 9      | Budget Planner                        | Suggests savings and investment plans. |
| 10     | Net Worth Calculator                  | Calculates current net worth. |
| 11     | Loan Eligibility prediction using AI  | AI based loan predictor based on age, credit score etc.|
